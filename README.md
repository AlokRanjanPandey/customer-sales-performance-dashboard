# Customer Sales Performance Dashboard

## 📊 Project Overview

This project is an Excel-based Business Analytics dashboard designed to analyze customer and sales performance.

The dashboard transforms sales data into an interactive visual report using Pivot Tables, charts, KPIs, and filters to support data-driven business decision-making.

## 🎯 Business Objective

The main objective of this project is to analyze sales and customer data, identify important performance trends, compare business segments and products, and present the results through an interactive Excel dashboard.

## 🔍 Analysis

The dashboard provides a consolidated view of customer and sales performance and helps identify trends and patterns within the available data.

The analysis covers:

- Customer performance analysis
- Sales performance analysis
- Profitability analysis
- Product performance
- Country-level performance
- Business segment performance
- Sales and profit trends over time
- KPI-based reporting
- Interactive dashboard analysis

## 📌 Key Observations

### Product Performance

The dashboard allows users to compare performance across products including:

- Amarilla
- Carretera
- Montana
- Paseo
- Velo
- VTT

### Country Performance

Performance can be analyzed across multiple countries, including:

- Canada
- France
- Germany
- Mexico
- United States

### Segment Performance

The dashboard compares sales and profit across different business segments, including:

- Government
- Small Business
- Enterprise
- Midmarket
- Channel Partners

The Government segment appears to be the strongest contributor to overall sales and profit, while the Enterprise segment shows a profitability concern that requires further investigation.

### Time-Based Analysis

The dashboard tracks sales and profit across monthly periods, making it possible to identify changes in performance and business trends over time.
